Where the research changed the roadmap's assumptions

  • Three pieces are separate plugins. In 2026.9.7, iMessage (@openclaw/imessage), Brave Search and the Prometheus exporter (@openclaw/diagnostics-prometheus) are installed from npm, not bundled. They're pinned at 2026.9.7 and must be updated together with OpenClaw.
  • Per-agent keys can't go through models auth paste-api-key. It stores the key itself in the agent's SQLite database. Per-person provider ids with Keychain SecretRefs keep every key in happy's Keychain instead; modelPolicy.allow stops one person's agent using another's provider.
  • main can't be renamed in place. Its database records its owner, and agents delete main refuses until openclaw doctor --fix moves the legacy shared auth store out of it (tested 2 Oct). D2–D3 add tony-main beside it, migrate, then delete.
  • A multi-agent config must say agents.ownership: "explicit", and the default 30-minute heartbeat would run a cloud turn and message the first allowlisted handle. Heartbeats are turned off.
  • web_search has to be allowed twice: in the agent's tools and in its sandbox tool list; otherwise it's filtered out without an error. TOOLS.md and HEARTBEAT.md are no longer injected; the hard rules live in AGENTS.md.
  • On iMessage, allowFrom is also the approver list, and native approval prompts need approvals.exec.enabled: true. A sandboxed command can never raise an approval, so E7 tests the path with the owner-only /diagnostics command, which always asks.
  • A dropped unknown sender is logged only at debug level, so E4–E6 run with debug logging and then switch it back.
  • The OpenAI-compatible endpoint can't be limited to loopback: with Tailscale Serve on, it's also reachable over the tailnet with the gateway token. The token already grants full operator access over the WebSocket API, so this adds a surface, not a credential.
  • promptfoo can't see OpenClaw's internal tool calls (OpenClaw continues a trace only for WebSocket requests that send traceparent), so happy-eval exports each eval session's trajectory and checks it itself. promptfoo still sends one "telemetry disabled" event per run even with telemetry off.
  • Grafana 13.2 treats its Prometheus datasource as a separate plugin kept current by a startup preinstaller (turned off here, so F2 installs it by hand and F5 checks it answers), and Grafana, macmon and node_exporter all listen on every interface by default; each is pinned to 127.0.0.1 here. For the metrics endpoint the docs show only the shared gateway token, which carries full operator access.

#!/bin/zsh -f
# happy-deploy: apply the staged, committed config as the happy user.
# Installed root:wheel 755 at /usr/local/libexec/happy-deploy; tonyli runs it through /etc/sudoers.d/happy:
#   sudo -u happy /usr/local/libexec/happy-deploy [--restart] [--restart-o1] [--flat]
#   sudo -u happy /usr/local/libexec/happy-deploy --run-eval     (only start the eval job; deploys nothing)
# --flat deploys openclaw.flat.json5 (the same config with its include merged in) as openclaw.json,
# because OpenClaw refuses `plugins install/update` while openclaw.json has a root $include. Use it
# only around a plugin change; the next normal deploy puts the include back (drift says DRIFT meanwhile).
# Order: folders and the resolver first (config validation checks the resolver's path and owner),
# then the config pair (openclaw.json + its generated include), which is all-or-nothing, then
# everything else. A rejected config stops the deploy before step 3.
# The gateway watches openclaw.json and its include and hot-applies them, restarting itself when a
# change needs it (gateway.reload.mode "hybrid"). After a normal deploy it starts the eval job, which
# runs only if the critical path (agents, prompts, models, routing, versions) changed.
set -euo pipefail
umask 077
[[ "$(/usr/bin/id -un)" == happy ]] || { print -u2 "happy-deploy: must run as happy"; exit 1; }
export HOME=/Users/happy
export PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin
cd "$HOME"

restart=0; restart_o1=0; flat=0; run_eval=0
for arg in "$@"; do
  case $arg in
    --restart) restart=1 ;; --restart-o1) restart_o1=1 ;; --flat) flat=1 ;; --run-eval) run_eval=1 ;;
    *) print -u2 "happy-deploy: unknown option $arg"; exit 2 ;;
  esac
done
evaljob="gui/$(/usr/bin/id -u)/local.happy.eval"
if (( run_eval )); then   # on demand: start the eval job with its force flag; nothing is deployed
  (( $# == 1 )) || { print -u2 "happy-deploy: --run-eval can't be combined with other options"; exit 2; }
  job=$(/bin/launchctl print "$evaljob" 2>/dev/null) || { print -u2 "happy-deploy: the eval job isn't loaded (runbook G3)"; exit 1; }
  if [[ $job == *'state = running'* ]]; then   # a string test, not grep -q: pipefail + SIGPIPE would misread it
    print "happy-deploy: an eval is already running; its result arrives through ntfy. Start another after that."
    exit 0
  fi
  /usr/bin/touch "$HOME/.config/happy/eval-force"
  /bin/launchctl kickstart "$evaljob" \
    || { /bin/rm -f "$HOME/.config/happy/eval-force"; print -u2 "happy-deploy: could not start the eval job"; exit 1; }
  print "happy-deploy: eval started; the result arrives through ntfy in 10-20 minutes"
  exit 0
fi

stage=/usr/local/var/happy-stage/current
[[ -r "$stage/REVISION" ]] || { print -u2 "happy-deploy: nothing staged at $stage"; exit 1; }
rev=$(<"$stage/REVISION")
state=$HOME/.openclaw
cfg=$HOME/.config/happy
meta="$HOME/Library/Application Support/happy-deploy"

/usr/bin/install -d -m 700 "$state" "$state/bin" "$state/sandboxes" "$HOME/bin" "$cfg" \
  "$HOME/Library/Logs/openclaw" "$HOME/Library/Logs/happy" "$HOME/Library/Logs/happy/eval" \
  "$HOME/Library/Logs/happy/grafana" "$HOME/Backups/openclaw" "$HOME/.local/share/victoriametrics" \
  "$HOME/.local/share/grafana" "$meta"
/usr/bin/install -d -m 755 "$HOME/Library/LaunchAgents"

# 0. Per-agent folders listed by the generator (workspaces, agent dirs, sandbox roots).
if [[ -r "$stage/openclaw/dirs.txt" ]]; then
  while IFS= read -r d; do
    [[ -z $d ]] && continue
    [[ $d == $state/* && $d != *..* ]] || { print -u2 "happy-deploy: refusing folder outside $state: $d"; exit 1; }
    /usr/bin/install -d -m 700 "$d"
  done < "$stage/openclaw/dirs.txt"
fi

# 1. The exec SecretRef provider: OpenClaw requires it to be owned by happy and not group/world-writable.
/usr/bin/install -m 700 "$stage/openclaw/bin/keychain-resolver" "$state/bin/keychain-resolver"

# 1b. Our own plugins (repo plugins/), loaded through plugins.load.paths. They go in before the config
#     that names them is validated. OpenClaw refuses plugin paths that others can write, hence go-rwx.
#     A running gateway keeps the old code until it restarts: deploy plugin changes with --restart.
if [[ -d "$stage/plugins" ]]; then
  /bin/rm -rf "$cfg/plugins.new"; /bin/cp -R "$stage/plugins" "$cfg/plugins.new"; /bin/chmod -R go-rwx "$cfg/plugins.new"
  /bin/rm -rf "$cfg/plugins"; /bin/mv "$cfg/plugins.new" "$cfg/plugins"
fi

# 2. Config. Validate a candidate copy of the pair first (the include must sit beside the file that
#    names it); the live files are replaced only if it passes. The include goes in first, so the
#    watcher's last event is openclaw.json.
cand="$meta/candidate"
/bin/rm -rf "$cand"; /usr/bin/install -d -m 700 "$cand"
if (( flat )); then
  /usr/bin/install -m 600 "$stage/openclaw/openclaw.flat.json5" "$cand/openclaw.json"
else
  for f in openclaw.json family.generated.json5; do
    [[ -r "$stage/openclaw/$f" ]] && /usr/bin/install -m 600 "$stage/openclaw/$f" "$cand/$f"
  done
fi
if ! OPENCLAW_CONFIG_PATH="$cand/openclaw.json" openclaw config validate; then
  print -u2 "happy-deploy: candidate config is invalid; live config left unchanged"
  exit 1
fi
[[ -f "$cand/family.generated.json5" ]] && /bin/mv -f "$cand/family.generated.json5" "$state/family.generated.json5"
/bin/mv -f "$cand/openclaw.json" "$state/openclaw.json"   # same volume, so this is an atomic rename

# 3. Bootstrap files the repo owns (hard rules, persona): openclaw/people/** and openclaw/shared/**.
#    Agents can't write them (no file tools); MEMORY.md and memory/ are never touched.
for f in "$stage"/openclaw/{people,shared}/**/*.md(N.); do
  rel=${f#$stage/openclaw/}
  [[ ${rel:t} == MEMORY.md || $rel == */memory/* ]] && continue
  /usr/bin/install -d -m 700 "$state/${rel:h}"
  /usr/bin/install -m 600 "$f" "$state/$rel"
done

# 4. Helper scripts, runtime values, observability and eval files, LaunchAgents (copied only; the
#    first load is by hand as happy).
for f in "$stage"/bin/*(N); do /usr/bin/install -m 700 "$f" "$HOME/bin/${f:t}"; done
for f in "$stage"/runtime/*(N); do /usr/bin/install -m 600 "$f" "$cfg/${f:t}"; done
for d in observability evals; do
  if [[ -d "$stage/$d" ]]; then
    /bin/rm -rf "$cfg/$d.new"; /bin/cp -R "$stage/$d" "$cfg/$d.new"; /bin/chmod -R go-rwx "$cfg/$d.new"
    /bin/rm -rf "$cfg/$d"; /bin/mv "$cfg/$d.new" "$cfg/$d"
  fi
done
for p in "$stage"/launchd/*.plist(N); do
  /usr/bin/plutil -lint -s "$p"
  /usr/bin/install -m 644 "$p" "$HOME/Library/LaunchAgents/${p:t}"
done

print -r -- "$(/bin/date -u +%Y-%m-%dT%H:%M:%SZ) $rev" >> "$meta/history.log"
print "happy-deploy: applied $rev (the gateway hot-reloads openclaw.json and its include)"

# 5. Optional restarts.
(( flat )) && print "happy-deploy: FLAT config deployed for plugin maintenance; deploy normally when done"
(( restart )) && openclaw gateway restart
if (( ! flat )) && /bin/launchctl print "$evaljob" >/dev/null 2>&1; then
  /bin/launchctl kickstart "$evaljob" >/dev/null 2>&1 \
    && print "happy-deploy: eval job started; it runs the suite only if the critical path changed" \
    || print "happy-deploy: eval job already running"
fi
if (( restart_o1 )); then   # Grafana reads provisioning, and VictoriaMetrics its scrape file, only at start
  for l in victoriametrics grafana macmon node-exporter sandbox-check; do
    /bin/launchctl print "gui/$(/usr/bin/id -u)/local.happy.$l" >/dev/null 2>&1 \
      && /bin/launchctl kickstart -k "gui/$(/usr/bin/id -u)/local.happy.$l" && print "restarted local.happy.$l"
  done
fi
exit 0

#!/bin/zsh -f
# happy-inspect: read-only views of happy's runtime for the admin account.
# Installed root:wheel 755 at /usr/local/libexec/happy-inspect; tonyli runs it through /etc/sudoers.d/happy:
#   sudo -u happy /usr/local/libexec/happy-inspect <command> [arg]
# Treat the output as untrusted data: logs, sessions and audits can contain text that came from
# models or message senders.
set -uo pipefail
[[ "$(/usr/bin/id -un)" == happy ]] || { print -u2 "happy-inspect: must run as happy"; exit 1; }

export PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin

# separation: every agent must point only at its owner's folders, provider and handles (roadmap §1b).
separation() {
  local entries bindings links allow owner fail=0
  entries=$(openclaw config get agents.entries --json) || { print "cannot read agents.entries"; return 1; }
  bindings=$(openclaw config get bindings --json) || return 1
  links=$(openclaw config get session.identityLinks --json 2>/dev/null) || links='{}'   # unset: error JSON, exit 1
  allow=$(openclaw config get channels.imessage.allowFrom --json 2>/dev/null) || allow='[]'
  owner=$(openclaw config get commands.ownerAllowFrom --json 2>/dev/null) || owner='[]'
  print -r -- "$entries" | $jq -r --arg S "$S" '
    to_entries[] | .key as $id | .value as $a |
    if ($id | test("^[a-z][a-z0-9]*-main(-eval)?$")) then
      ($id | capture("^(?<p>[a-z][a-z0-9]*)-main(?<e>-eval)?$")) as $m |
      ("main" + ($m.e // "")) as $pur |
      (if $m.e then "openai-eval" else "openai-" + $m.p end) as $prov |
      [ (if $a.workspace == "\($S)/people/\($m.p)/main/workspace" then empty else "workspace \($a.workspace)" end),
        (if $a.agentDir == "\($S)/people/\($m.p)/\($pur)/agent" then empty else "agentDir \($a.agentDir)" end),
        (if $a.sandbox.workspaceRoot == "\($S)/sandboxes/\($m.p)/\($pur)" then empty else "sandbox root \($a.sandbox.workspaceRoot)" end),
        (if ($a.model.primary | startswith($prov + "/")) then empty else "model \($a.model.primary)" end),
        (if ($a.model.fallbacks // ["x"]) == [] then empty else "fallbacks not empty" end),
        (if ([$a.modelPolicy.allow[]? | startswith($prov + "/")] | length > 0 and all) then empty else "modelPolicy.allow \($a.modelPolicy.allow)" end),
        (if (($a.utilityModel // "") | startswith($prov + "/")) then empty else "utilityModel \($a.utilityModel)" end),
        (if ($a.subagents.allowAgents // ["x"]) == [] then empty else "handoffs \($a.subagents.allowAgents)" end),
        (if ([$a.tools.deny[]?] | index("group:messaging")) then empty else "message tool not denied" end)
      ] | if length == 0 then "ok   \($id): folders of \($m.p), provider \($prov)" else "FAIL \($id): " + join("; ") end
    elif $id == "inbox" then
      [ (if $a.workspace == "\($S)/shared/inbox/workspace" then empty else "workspace" end),
        (if $a.agentDir == "\($S)/shared/inbox/agent" then empty else "agentDir" end),
        (if $a.sandbox.workspaceRoot == "\($S)/sandboxes/shared/inbox" and $a.sandbox.scope == "session" then empty else "sandbox" end),
        (if $a.tools.deny == ["*"] then empty else "tools not all denied" end),
        (if $a.memory.search.enabled == false and $a.memory.search.rememberAcrossConversations == false then empty else "memory on" end),
        (if ($a.model.primary | startswith("openai-shared/")) and ($a.model.fallbacks == []) then empty else "model" end)
      ] | if length == 0 then "ok   inbox: shared, no tools, no memory" else "FAIL inbox: " + join("; ") end
    else "FAIL \($id): not a known agent shape" end' || fail=1
  # no two agents share an agentDir or a sandbox root
  print -r -- "$entries" | $jq -r '[.[] | .agentDir] | group_by(.) | map(select(length > 1)) | .[] | "FAIL shared agentDir \(.[0])"'
  print -r -- "$entries" | $jq -r '[.[] | .sandbox.workspaceRoot] | group_by(.) | map(select(length > 1)) | .[] | "FAIL shared sandbox root \(.[0])"'
  # bindings: a handle may only route to the main agent of the person whose identity links list it;
  # the only binding without a peer is the inbox catch-all; eval clones are never bound
  $jq -rn --argjson b "$bindings" --argjson l "$links" '
    $b[] | .agentId as $id |
    if .match.peer then
      (.match.peer.id) as $h |
      ([$l | to_entries[] | select(.value | index("imessage:" + $h)) | .key]) as $who |
      if ($id | endswith("-eval")) then "FAIL eval clone \($id) is bound"
      elif ($who | length) == 1 and $id == ($who[0] + "-main") then "ok   binding \($h) -> \($id)"
      else "FAIL binding \($h) -> \($id) (identity links say \($who))" end
    elif $id == "inbox" and .match.accountId == "*" then "ok   catch-all -> inbox"
    else "FAIL binding without a peer -> \($id)" end'
  $jq -rn --argjson a "$allow" --argjson l "$links" --argjson o "$owner" '
    ([$l[][]] | map(sub("^imessage:"; ""))) as $known |
    ($a[] as $h | select(($known | index($h)) | not) | "FAIL allowFrom \($h) has no identity link"),
    (if ([$a[] as $h | select($known | index($h))] | length) == ($a | length) then "ok   allowFrom: \($a | length) handle(s), all linked: \($a | join(", "))" else empty end),
    (if ($o | length) == 1 and ($known | index($o[0] | sub("^imessage:"; ""))) then "ok   command owner \($o[0])" else "FAIL command owner \($o)" end)'
  # no gateway-wide or ambient credentials left to fall back to
  openclaw config get models.providers.openai --json >/dev/null 2>&1 \
    && print "FAIL models.providers.openai is set" || print "ok   no gateway-wide openai provider key"
  [[ -e $S/.env ]] && print "FAIL $S/.env exists" || print "ok   no ~/.openclaw/.env"
  for a in ${(f)"$(print -r -- "$entries" | $jq -r 'keys[]')"}; do
    openclaw models status --agent "$a" --json 2>/dev/null | $jq -r --arg a "$a" '
      ([.auth.providers[]?.profiles.count] | add // 0) as $n |
      if $n == 0 then "ok   \($a): no stored auth profiles; allowed \(.allowed | join(", "))"
      else "FAIL \($a): \($n) stored auth profile(s)" end'
  done
  # shared agents keep no memory files
  [[ -e $S/shared/inbox/workspace/MEMORY.md || -d $S/shared/inbox/workspace/memory ]] \
    && print "FAIL inbox workspace has memory files" || print "ok   inbox workspace has no memory files"
  [[ "$(openclaw config get plugins.entries.memory-core.config.dreaming.enabled 2>/dev/null)" == false ]] \
    && print "ok   dreaming off" || print "FAIL dreaming is not off"
}

// nws.js: National Weather Service client for the home_weather tool. No dependencies: the caller
// passes fetch. It only ever contacts https://api.weather.gov, and it refuses redirects and any
// forecast URL that the points lookup returns on another host.
//
// API: https://www.weather.gov/documentation/services-web-api
//   GET /points/{lat},{lon}            -> properties.forecast (gridpoint URL), timeZone
//   GET /gridpoints/{wfo}/{x},{y}/forecast -> properties.periods (12-hour periods), updateTime
//   GET /alerts/active?point={lat},{lon}   -> features[].properties (event, headline, ends)
// NWS asks every client to send a User-Agent that names the app and a contact.

const API = "https://api.weather.gov";
const POINTS_TTL_MS = 24 * 60 * 60 * 1000; // a grid assignment changes very rarely
const FORECAST_TTL_MS = 10 * 60 * 1000;    // NWS refreshes forecasts about hourly
const TIMEOUT_MS = 8000;

/** Collapses whitespace, drops control characters and caps the length of text from the API. */
export function clip(value, max) {
  if (value === null || value === undefined) return "";
  const text = String(value).replace(/[\u0000-\u001f\u007f]+/g, " ").replace(/\s+/g, " ").trim();
  return text.length > max ? `${text.slice(0, max - 1)}…` : text;
}

/** NWS wants at most four decimals and no trailing zeros (it redirects otherwise). */
export function coord(value, min, max) {
  const n = Number(value);
  if (!Number.isFinite(n) || n < min || n > max) throw new Error(`coordinate out of range: ${value}`);
  return String(Number(n.toFixed(4)));
}

/** The human-readable forecast page for the same point, for the reply's source link. */
export function sourceUrl(latitude, longitude) {
  return `https://forecast.weather.gov/MapClick.php?lat=${coord(latitude, -90, 90)}&lon=${coord(longitude, -180, 180)}`;
}

function apiUrl(value) {
  let url;
  try { url = new URL(value); } catch { return null; }
  return url.protocol === "https:" && url.hostname === "api.weather.gov" ? url.href : null;
}

function number(value) {
  const n = Number(value);
  return value === null || value === undefined || !Number.isFinite(n) ? null : n;
}

export function createNwsClient({ userAgent, fetchImpl = (...args) => globalThis.fetch(...args),
                                  now = () => Date.now(),
                                  sleep = (ms) => new Promise((r) => setTimeout(r, ms)) }) {
  if (!userAgent || typeof userAgent !== "string") throw new Error("home-weather: userAgent is required");
  const cache = new Map(); // url -> { at, body }

  async function getJson(url, ttl, signal) {
    const hit = cache.get(url);
    if (hit && now() - hit.at < ttl) return hit.body;
    let lastError;
    for (let attempt = 0; attempt < 2; attempt++) {   // one retry: NWS returns brief 5xx at times
      if (attempt) await sleep(1000);
      const timeout = AbortSignal.timeout(TIMEOUT_MS);
      try {
        const res = await fetchImpl(url, {
          headers: { "User-Agent": userAgent, Accept: "application/geo+json" },
          redirect: "error",
          signal: signal ? AbortSignal.any([signal, timeout]) : timeout,
        });
        if (res.status === 200) {
          const body = await res.json();
          cache.set(url, { at: now(), body });
          return body;
        }
        lastError = new Error(`HTTP ${res.status} from api.weather.gov`);
        if (res.status < 500 && res.status !== 429) break;
      } catch (err) {
        if (signal?.aborted) throw err;
        lastError = err;
      }
    }
    throw lastError;
  }

  /** Forecast periods for the next `days` days (two 12-hour periods a day) and active alerts. */
  async function getForecast({ latitude, longitude, place, days = 2, signal }) {
    const lat = coord(latitude, -90, 90);
    const lon = coord(longitude, -180, 180);
    const points = await getJson(`${API}/points/${lat},${lon}`, POINTS_TTL_MS, signal);
    const forecastUrl = apiUrl(points?.properties?.forecast);
    if (!forecastUrl) throw new Error("points lookup returned no api.weather.gov forecast URL");
    const timeZone = clip(points?.properties?.timeZone, 64) || "America/New_York";
    const [forecast, alerts] = await Promise.all([
      getJson(forecastUrl, FORECAST_TTL_MS, signal),
      getJson(`${API}/alerts/active?point=${lat},${lon}`, FORECAST_TTL_MS, signal).catch(() => null),
    ]);
    const count = Math.min(14, Math.max(1, Math.trunc(days)) * 2);
    const periods = (Array.isArray(forecast?.properties?.periods) ? forecast.properties.periods : [])
      .slice(0, count)
      .map((p) => ({
        name: clip(p?.name, 40),
        isDaytime: Boolean(p?.isDaytime),
        temperature: number(p?.temperature),
        unit: p?.temperatureUnit === "C" ? "C" : "F",
        precipitationChance: number(p?.probabilityOfPrecipitation?.value),
        wind: clip(`${p?.windDirection ?? ""} ${p?.windSpeed ?? ""}`, 40),
        summary: clip(p?.shortForecast, 80),
        detail: clip(p?.detailedForecast, 300),
      }));
    if (!periods.length) throw new Error("the forecast had no periods");
    const updatedRaw = forecast?.properties?.updateTime ?? forecast?.properties?.generatedAt;
    const updatedDate = new Date(updatedRaw);
    const updated = Number.isNaN(updatedDate.getTime()) ? "unknown"
      : updatedDate.toLocaleString("en-US", { timeZone, dateStyle: "medium", timeStyle: "short" });
    return {
      place: clip(place, 80),
      source: "National Weather Service",
      sourceUrl: sourceUrl(lat, lon),
      updated,
      periods,
      alerts: alerts === null ? null
        : (Array.isArray(alerts?.features) ? alerts.features : []).slice(0, 5).map((f) => ({
            event: clip(f?.properties?.event, 80),
            severity: clip(f?.properties?.severity, 20),
            headline: clip(f?.properties?.headline, 200),
            ends: clip(f?.properties?.ends ?? f?.properties?.expires, 40),
          })),
    };
  }

  return { getForecast };
}

/** The text the model sees: one line per period, alerts first. */
export function formatText(r) {
  const lines = [
    `${r.source} forecast for ${r.place}, updated ${r.updated}.`,
    `Source link: ${r.sourceUrl}`,
    r.alerts === null ? "Active alerts: could not be checked."
      : r.alerts.length ? `Active alerts: ${r.alerts.map((a) => `${a.event} (${a.severity}): ${a.headline}`).join(" | ")}`
      : "Active alerts: none.",
  ];
  for (const p of r.periods) {
    const temp = p.temperature === null ? "" : ` ${p.isDaytime ? "High" : "Low"} ${p.temperature}°${p.unit}.`;
    const rain = p.precipitationChance === null ? "" : ` Chance of precipitation ${p.precipitationChance}%.`;
    const wind = p.wind ? ` Wind ${p.wind}.` : "";
    lines.push(`- ${p.name}: ${p.summary}.${temp}${rain}${wind} ${p.detail}`.replace(/\.\./g, "."));
  }
  return lines.join("\n");
}

# happy-eval: the E0 run, as happy. Never scheduled; it runs
#   - on demand: `happy-eval` in happy's Terminal, or `scripts/run-eval.sh` (happy-deploy --run-eval)
#     from the admin account, which starts local.happy.eval with a "force" flag;
#   - after a deploy: happy-deploy starts local.happy.eval, which runs `happy-eval --if-changed`.
#     That run goes ahead only if the critical path changed since the last run (see fingerprint()).
# Steps:
#   1. plant each person's separation canary in their MEMORY.md (idempotent)
#   2. run the canary sets against the eval clones, then check their exported trajectories:
#      the clone's own marker present, no other person's marker anywhere, no tool call but web_search
#      and home_weather
#   3. run the smoke set against tony-main-eval
#   4. push the result to your phone (ntfy: counts only, never message content) and per-suite
#      pass/fail counts plus the run result into VictoriaMetrics for Grafana
# Results: ~/Library/Logs/happy/eval/<date-time>/ (HTML, JSON, logs, summary.txt, trajectories).
# Fails closed: missing canaries, sessions or exports count as failures.
set -uo pipefail

# The critical path: everything that changes what an agent is, knows or may do, and the versions
# that run it. Logging, observability, Tailscale and channel on/off are deliberately left out.
fingerprint() {
  { openclaw --version
    openclaw plugins list --json 2>/dev/null \
      | /usr/bin/jq -S -c '[.plugins[] | select(.id == "imessage" or .id == "brave" or .id == "diagnostics-prometheus" or .id == "home-weather") | {id, version}]'
    for k in agents models tools bindings session commands approvals memory \
             channels.imessage.allowFrom channels.imessage.dmPolicy plugins.entries.brave \
             plugins.entries.home-weather plugins.load; do
      print -r -- "== $k"; openclaw config get "$k" --json 2>/dev/null | /usr/bin/jq -S -c .
    done
    for f in $S/people/*/*/workspace/{AGENTS,SOUL,IDENTITY,USER}.md(N) $S/shared/*/workspace/*.md(N) \
             $evals/*.yaml(N) $evals/canaries.tsv(N) $cfg/plugins/**/*(.N); do   # our own plugin code too
      print -r -- "== $f"; /bin/cat "$f"
    done
  } | /usr/bin/shasum -a 256 | /usr/bin/cut -c1-64
}

  note "$name: promptfoo exit $rc (0 = all passed, 100 = a test failed)"
  (( rc == 0 )) || fail=1
  [[ -r $out/$name.json ]] && read -r p f e <<< "$(/usr/bin/jq -r \
    '[.results.stats.successes // 0, .results.stats.failures // 0, .results.stats.errors // 0] | @tsv' "$out/$name.json" 2>/dev/null)"
  totals+="$name ${p:-0}/$(( ${p:-0} + ${f:-0} + ${e:-0} )) passed, "
  print -r -- "openclaw_eval_tests{suite=\"$name\",result=\"passed\"} ${p:-0}
openclaw_eval_tests{suite=\"$name\",result=\"failed\"} ${f:-0}
openclaw_eval_tests{suite=\"$name\",result=\"error\"} ${e:-0}" | vmpush
}
sessionkeys() { openclaw sessions --agent "$1" --limit all --json 2>/dev/null | /usr/bin/jq -r '.sessions[].key'; }
typeset -A before                                  # each clone's sessions before the canaries run
for person in ${(k)phrase}; do before[$person]=$(sessionkeys "${agent_of[$person]}"); done
for suite in canary-*.yaml(N); do run "$suite"; done

# Trajectory check, per eval clone: only the sessions this canary run created.
for person in ${(k)phrase}; do
  agent=${agent_of[$person]}
  old=("${(@f)before[$person]}")
  keys=("${(@f)$(sessionkeys "$agent")}")
  keys=(${keys:#}); keys=(${keys:|old})             # drop empty lines and pre-existing sessions
  (( ${#keys} )) || { note "FAIL $agent: no sessions from this run to check"; fail=1; continue; }
  for k in $keys; do
    n=$(print -rn -- "$k" | /usr/bin/shasum -a 256 | /usr/bin/cut -c1-12)
    if ! openclaw sessions export-trajectory --agent "$agent" --session-key "$k" --workspace "$out/traj" \
         --output "$agent-$n" > /dev/null 2>> "$out/traj-export.log"; then
      note "FAIL $agent: export failed for $k: $(/usr/bin/grep -v '^\s*$' "$out/traj-export.log" | /usr/bin/tail -n 1 | /usr/bin/cut -c1-200)"
      fail=1
    fi
  done
  dirs=("$out"/traj/.openclaw/trajectory-exports/$agent-*(N/))
  evs=("$out"/traj/.openclaw/trajectory-exports/$agent-*/events.jsonl(N))
  (( ${#evs} == ${#keys} )) || { note "FAIL $agent: ${#evs} event files for ${#keys} sessions"; fail=1; }
  (( ${#evs} )) || continue
  # web_search and home_weather are the clones' only tools: search queries are covered by the marker
  # check below, and home_weather takes no input but a day count. Any other tool call fails the run.
  if calls=$(/bin/cat $evs | /usr/bin/jq -r 'select(.type == "tool.call") | .data.name' | /usr/bin/sort | /usr/bin/uniq -c); then
    other=$(print -r -- "$calls" | /usr/bin/grep -v -E '^ *[0-9]+ (web_search|home_weather)$' | /usr/bin/grep -v '^$')
    if [[ -n $other ]]; then note "FAIL $agent: tool calls: ${other//$'\n'/, }"; fail=1
    elif [[ -n $calls ]]; then note "ok   $agent: only web_search/home_weather calls (${calls//$'\n'/, }) in ${#keys} sessions"
    else note "ok   $agent: no tool calls in ${#keys} sessions"; fi
  else
    note "FAIL $agent: could not parse events.jsonl"; fail=1
  fi
  # The export must contain the clone's own marker (proof that the injected context was captured);
  # only then does the absence of anyone else's marker mean something.
  /usr/bin/grep -rqiF -- "${phrase[$person]}" $dirs; rc=$?
  (( rc == 0 )) && note "ok   $agent: its own marker is in the exported context" \
                || { note "FAIL $agent: own marker not found in the export (grep exit $rc)"; fail=1; }
  for other in ${(k)phrase}; do
    [[ $other == $person ]] && continue
    /usr/bin/grep -rqiF -- "${phrase[$other]}" $dirs; rc=$?
    case $rc in
      1) note "ok   $agent: no trace of ${other}'s marker" ;;
      0) note "FAIL $agent: ${other}'s marker appears in its trajectories"; fail=1 ;;
      *) note "FAIL $agent: grep error $rc while checking for ${other}'s marker"; fail=1 ;;
    esac
  done
done

for suite in smoke.yaml(N); do run "$suite"; done
unset OPENCLAW_GATEWAY_TOKEN

print -r -- "openclaw_eval_run_passed $(( fail == 0 ? 1 : 0 ))" | vmpush
print -r -- "$fp" > "$cfg/eval-fingerprint"              # what this run tested, pass or fail
result=$([[ $fail == 0 ]] && print PASS || print FAIL)
note "== $(/bin/date -u +%Y-%m-%dT%H:%M:%SZ) eval end: $result"
checks=$(/usr/bin/grep -c '^FAIL' "$out/summary.txt")
notify "Evals $result ($trigger)" "${totals%, }; $checks failed check(s). Details: happy-inspect eval-latest"
# A deploy during the run couldn't start the job (it was running), so check for a change once more.
if [[ $(fingerprint) != "$fp" ]]; then
  print "happy-eval: the critical path changed during this run; checking again"
  exec "$self" --if-changed
fi
exit $fail

#!/bin/zsh -f
# happy-sandbox-check: run every minute by local.happy.sandbox-check (O1). Asks the Docker engine inside
# Colima whether it answers and whether the sandbox image is still there, and pushes the answer to
# VictoriaMetrics as happy_sandbox_ready (1 or 0) for Grafana's "Sandbox runtime down" rule.
# Why: /readyz doesn't cover the sandbox. With Colima down the gateway stays ready, but every
# sandboxed tool call fails (M0 sign-off). If this job stops pushing, the rule fires too.
set -u
export HOME=/Users/happy
export PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin
image=openclaw-sandbox:bookworm-slim                 # agents.defaults.sandbox.docker.image
limit() { /usr/bin/perl -e 'alarm shift; exec @ARGV' "$@"; }   # macOS has no timeout(1); a hung VM must not hang this
ready=0
if limit 20 docker info --format '{{.ServerVersion}}' >/dev/null 2>&1; then
  if limit 20 docker image inspect "$image" >/dev/null 2>&1; then ready=1
  else print "happy-sandbox-check: $(/bin/date -u +%FT%TZ) engine answers but $image is missing"; fi
else
  print "happy-sandbox-check: $(/bin/date -u +%FT%TZ) the Docker engine in Colima doesn't answer"
fi
print -r -- "happy_sandbox_ready $ready" \
  | /usr/bin/curl -fsS -m 5 --data-binary @- http://127.0.0.1:8428/api/v1/import/prometheus >/dev/null \
  || print "happy-sandbox-check: $(/bin/date -u +%FT%TZ) could not push to VictoriaMetrics"
exit 0
bin/happy-o1-drill (F7's drill, in order)
#!/bin/zsh
# happy-o1-drill: M1 F7, the O1 alert drill, end to end. Run it in happy's own Terminal (GUI session):
#   ~/bin/happy-o1-drill
# It stops and restarts macmon, then Grafana, then Colima, and watches Grafana's alert states and the
# sandbox metric instead of fixed timers, printing ">>> PUSH" when a push should have reached your
# phone. Only part 2 waits on the clock: reading healthchecks.io's status needs an API key this Mac
# doesn't hold. On any exit (Ctrl-C included) it starts the three services again.
# About 45 minutes. Don't text Happy during part 3: tools fail while the sandbox is down.
setopt err_exit pipe_fail no_unset

uid=$(id -u)
la=$HOME/Library/LaunchAgents
G=http://127.0.0.1:3000
VM=http://127.0.0.1:8428
jq=/usr/bin/jq
colima=/opt/homebrew/bin/colima
pwfile=$HOME/.config/happy/grafana-admin-password
typeset -a pushes

say() { print -r -- "[$(/bin/date +%H:%M:%S)] $*"; }
loaded() { launchctl print "gui/$uid/local.happy.$1" >/dev/null 2>&1; }
stop_svc() { if loaded $1; then launchctl bootout "gui/$uid/local.happy.$1"; fi; say "stopped $1"; }
start_svc() { if ! loaded $1; then launchctl bootstrap "gui/$uid" "$la/local.happy.$1.plist"; fi; say "started $1"; }
restore() {
  local s
  for s in macmon grafana colima; do
    loaded $s || launchctl bootstrap "gui/$uid" "$la/local.happy.$s.plist" 2>/dev/null || true
  done
}
trap 'print; say "exit: making sure macmon, grafana and colima are running"; restore' EXIT
trap 'exit 130' INT TERM

# Grafana API as admin; the password goes to curl on stdin, never on a command line.
gapi() { printf 'user = "admin:%s"\n' "$(<$pwfile)" | /usr/bin/curl -fsS -m 10 -K - "$G$1"; }

# State of a Grafana-managed rule: firing, pending, inactive (normal) or missing. Source: the
# Prometheus-compatible rules API; if that can't be read, the Alertmanager's active alerts.
rule_state() {
  local s
  s=$(gapi /api/prometheus/grafana/api/v1/rules 2>/dev/null | $jq -r --arg n "$1" \
        '[.data.groups[]?.rules[]? | select(.name == $n) | (.state // "unknown" | ascii_downcase)] | first // "missing"' 2>/dev/null) || s=""
  if [[ -z $s || $s == missing || $s == unknown ]]; then
    s=$(gapi /api/alertmanager/grafana/api/v2/alerts 2>/dev/null | $jq -r --arg n "$1" \
          'if any(.[]; .labels.alertname == $n and .status.state == "active") then "firing" else "inactive" end' 2>/dev/null) || s=unreachable
  fi
  print -r -- "$s"
}
is_firing() { [[ $(rule_state "$1") == firing ]]; }
is_clear() { local s; s=$(rule_state "$1"); [[ $s == inactive || $s == normal || $s == ok ]]; }
sandbox_metric() {
  /usr/bin/curl -fsS -m 5 "$VM/api/v1/query" --data-urlencode 'query=last_over_time(happy_sandbox_ready[3m])' \
    | $jq -r '.data.result[0].value[1] // "none"' 2>/dev/null || print none
}
sandbox_is() { [[ $(sandbox_metric) == $1 ]]; }
grafana_up() { /usr/bin/curl -fsS -m 3 "$G/api/health" 2>/dev/null | $jq -e '.database == "ok"' >/dev/null 2>&1; }
colima_running() { $colima status >/dev/null 2>&1; }

# wait_until <what> <limit in minutes> <command ...>: polls every 15 s; stops the drill on timeout.
wait_until() {
  local what=$1 limit=$(( $2 * 60 )) t0=$SECONDS
  shift 2
  say "waiting (up to $(( limit / 60 )) min): $what"
  until "$@"; do
    if (( SECONDS - t0 >= limit )); then say "TIMEOUT: $what. Drill stopped; tell Claude."; exit 1; fi
    sleep 15
  done
  say "  done after $(( (SECONDS - t0) / 60 ))m$(( (SECONDS - t0) % 60 ))s"
}
expect_push() { pushes+=("$(/bin/date +%H:%M)  $1"); say ">>> PUSH expected about now: $1"; }

# --- preflight: nothing is stopped unless all of this holds
grafana_up || { say "Grafana isn't healthy; nothing was stopped"; exit 1; }
[[ -r $pwfile ]] || { say "can't read $pwfile; run this as happy"; exit 1; }
for r in "Metrics exporter down" "Sandbox runtime down"; do
  s=$(rule_state "$r")
  case $s in
    inactive|normal|ok) ;;
    unreachable|missing|unknown) say "can't read the state of \"$r\" ($s); nothing was stopped; tell Claude"; exit 1 ;;
    *) say "\"$r\" is $s right now; wait until it clears, then run again"; exit 1 ;;
  esac
done
sandbox_is 1 || { say "the sandbox check doesn't read 1; fix Colima first; nothing was stopped"; exit 1; }
say "preflight ok. About 45 minutes; keep your iPhone near. Ctrl-C at any time restores the services."

# --- part 1: a Grafana alert reaches ntfy
say "PART 1 of 3: metrics exporter down (macmon)"
stop_svc macmon
wait_until '"Metrics exporter down" firing (scrapes every 30 s, then 5 min pending)' 10 is_firing "Metrics exporter down"
sleep 45                                   # notification policy: group_wait 30 s
expect_push "ntfy  FIRING: Metrics exporter down"
start_svc macmon
wait_until '"Metrics exporter down" back to normal' 5 is_clear "Metrics exporter down"
say "Grafana sends RESOLVED at its next group interval: up to 5 min"
sleep 300
expect_push "ntfy  RESOLVED: Metrics exporter down (may have come up to 5 min earlier)"

# --- part 2: a dead Grafana still reaches you, through healthchecks.io
say "PART 2 of 3: Grafana down; healthchecks.io must notice the missing watchdog pings (21 min)"
stop_svc grafana
for m in {1..21}; do
  sleep 60
  if (( m % 5 == 0 )); then say "  $m of 21 min"; fi
done
expect_push "healthchecks.io  \"agent-mini alerts\" is DOWN (expected 14 to 20 min after the stop)"
start_svc grafana
wait_until "Grafana healthy" 3 grafana_up
sleep 150                                  # rule evaluation every minute, then the watchdog's first ping
expect_push "healthchecks.io  \"agent-mini alerts\" is UP again"

# --- part 3: the sandbox check
say "PART 3 of 3: Colima down. Don't text Happy until the drill ends."
stop_svc colima
wait_until 'sandbox check reads 0' 4 sandbox_is 0
wait_until '"Sandbox runtime down" firing (3 min pending)' 8 is_firing "Sandbox runtime down"
sleep 45
expect_push "ntfy  FIRING: Sandbox runtime down"
start_svc colima
wait_until 'Colima running' 6 colima_running
wait_until 'sandbox check reads 1' 4 sandbox_is 1
wait_until '"Sandbox runtime down" back to normal' 5 is_clear "Sandbox runtime down"
say "Grafana sends RESOLVED at its next group interval: up to 5 min"
sleep 300
expect_push "ntfy  RESOLVED: Sandbox runtime down (may have come up to 5 min earlier)"

say "DRILL COMPLETE. You can text Happy again. The six pushes that should have arrived:"
for p in $pushes; do print -r -- "  $p"; done
say "Tell Claude which arrived, and paste this output."
