Section 1

Which agent platform to run

The "personal agent" category split in two during 2026. On one side are self-hosted open-source gateways you run on your own machine and connect to whatever models and chat apps you like. On the other are vendor-hosted agents that live in a cloud virtual machine the vendor controls. The question for a privacy-conscious home build is not which is more capable but where your data lives and who carries the security burden.

OpenClaw: the default choice, with eyes open

OpenClaw began life as "Clawdbot" in November 2025, was renamed twice after trademark complaints, and settled on its current name on 30 January 2026.1 It is MIT-licensed TypeScript with no paid tier or hosted service, and by September 2026 its repository sits around 390k GitHub stars, sixth all-time on GitHub.25 The architecture is a local Gateway process (control plane) with a Control UI, CLI, companion apps, and extension points for tools, SKILL.md-style skills, plugins and the ClawHub marketplace.27

Two governance events matter for a long-term bet. In February 2026 creator Peter Steinberger joined OpenAI; it was explicitly not an acquisition, and both parties committed to keeping the project open source in a foundation.6 In July 2026 the OpenClaw Foundation launched as a US 501(c)(3), chaired by Dave Morin, with core maintainers drawn from NVIDIA, Microsoft, OpenAI and Tencent and sponsorship from OpenAI, NVIDIA, GitHub, Microsoft, Red Hat, Vercel and Amazon.45 OpenClaw 2.0 (v2026.8.1) shipped at the end of August 2026 with 933 contributors, auto-detection of ChatGPT and Claude subscriptions plus local models, and a rebuilt browser UI.3

Meta Muse: what it is and why it is not this plan

Meta launched Muse on 8 September 2026 as "a secure, private personal AI agent" running on its Muse Spark model, with a free tier plus Power ($20/month) and Maximum ($100/month) plans; a payment card is required to start.1011 It is US-only at launch, on iOS, Android, muse.ai and inside WhatsApp. Every user gets a "Muse Secure VM", a dedicated cloud virtual machine with its own browser, overseen by a separate "Sentinel" agent that approves internet-bound actions. Meta promises a "Confidential VM" encrypted with a user-held key "later this year"; it had not shipped at launch.10 Muse connects to email, calendar, payments via Stripe Link, health apps, smart home, shopping and travel, each opt-in, and Meta says conversations are not shared with its ad systems and users can opt out of training.10

The first two weeks produced the criticism you would expect. An Inc. columnist who declined message access found Muse had synced a 187,462-row Messages database from his Mac, and the agent initially misdescribed what it had accessed.12 WIRED's reviewer, quoted by Futurism, said "every suggested interaction with Muse started to feel like a guise for me to upload more data."13 TechCrunch framed the launch against Meta's 2011 and 2019 FTC privacy orders and the $5 billion 2019 penalty.11 None of this makes Muse useless; it makes it the opposite of a local agent. Your data lives in Meta's VM, the model is Meta's, and the audit trail is Meta's to show you.

Open source versus proprietary: the real trade

Open source buys you auditability, the freedom to point sensitive tasks at a fully local model, no lock-in to one vendor's ecosystem, and a nonprofit steward. It also buys you the whole security burden. In 2026 that burden has been concrete: 12% of audited ClawHub skills were malicious at one point, the gateway shipped with a one-click RCE, and release cadence changes defaults faster than most users read changelogs.5354 Proprietary agents give you managed updates, polished confirmation flows and an audit trail, and they keep working when your laptop is closed. In exchange your inbox, messages and payment tokens live in a vendor's VM under a training and ads policy that is opt-out (Muse) or plan-gated (Spark), and you cannot swap the model.

One wrinkle affects the open-source path if you planned to reuse a Claude subscription. Anthropic blocked subscription OAuth tokens from third-party harnesses like OpenClaw on 4 April 2026, announced metered "Agent SDK credits" on 13 May, then paused that change on 16 June.2324 Its current legal page still says OAuth is intended exclusively for Claude Code and native apps and that third parties may not route requests through Pro or Max credentials.25 OpenAI, by contrast, explicitly supports ChatGPT subscription OAuth in external tools via Codex.105 The safe assumption: use an Anthropic API key for Claude inside OpenClaw; a ChatGPT Plus plan can legitimately cover the OpenAI share.

Recommendation

Start with OpenClaw for coverage and community, but run it as if it were hostile: dedicated macOS user account, loopback-only gateway reached over Tailscale, sandboxed tool execution, no unvetted ClawHub skills, and a pinned version you upgrade deliberately. If after a month the surface area feels unmanageable, NanoClaw gives you the same channels in a codebase small enough to read end to end, with container isolation as the default rather than an option.

Section 2

Hardware to host it

Two separate questions hide inside "what should I buy": what runs the agent runtime and browser 24/7, and what (if anything) runs local language models. The first is cheap; a Raspberry Pi or a $7/month VPS will do it. The second is where the money goes, and the deciding factor is unified memory bandwidth, not CPU speed.

Why people buy the Mac mini anyway

Cost alone does not justify it: an $899 mini versus a $6.49/month VPS takes over a decade to pay back. The reasons are functional. OpenClaw's iMessage channel reads Messages through imsg on a Mac signed into Messages.app with Full Disk Access; BlueBubbles support was removed, so a Mac is now effectively the only way to bridge iMessage.40 The mini idles at 4–6 W and is silent, which matters for a box that runs 24/7 in a home.32 Unified memory plus Apple's MLX framework, which Ollama adopted as its Apple Silicon backend in 2026, makes local models a one-command addition later.98 And a residential IP with a real desktop browser is what job boards and travel sites expect to see.

Memory rules of thumb

  • Weights: about 0.6 GB per billion parameters at 4-bit (Q4_K_M), 1.05 GB at 8-bit. So 8B ≈ 5 GB, 27B ≈ 16 GB, 32B ≈ 19.5 GB, 70B ≈ 42.5 GB, gpt-oss-120b (MXFP4) ≈ 63 GB.
  • KV cache is the hidden cost. The working memory for context scales with layers × KV heads × head dimension × tokens.41 For a 32B-class model at 32k context that is roughly 8 GB extra at FP16; for 70B at 128k it is ~40 GB, as much as the weights. Agents run long contexts, so budget for it.
  • Leave headroom: macOS lets the GPU use roughly 65–75% of RAM by default, and the agent runtime plus Chromium want 8–12 GB of their own.
  • Prefer mixture-of-experts locally. A model with 3–6B active parameters (Qwen3.6-35B-A3B, gpt-oss-20b, Gemma 4 26B-A4B) generates several times faster than a dense model of the same total size, because only the active experts move through memory each token.

Total cost of ownership

At the September 2026 US residential average of about 18¢/kWh, one watt running all year costs about $1.60. A Mac mini idling at 6 W with occasional local inference costs $16–40 a year in electricity; a DGX Spark idles at $35–60; a 5090 tower at $110–160. Against that, cloud API spend for a personal agent runs $6–13/month for light use and $25–50 for moderate use in published estimates, and heavy autonomous use with frontier models can reach hundreds.39 The $2,300 premium of the purchased $3,199 configuration over an $899 base M6 pays back in about 23 months if local models absorb $100/month of API calls, or about six and a half years at $30/month. In practice the hybrid split (local for the routine 70–80% of requests, cloud for hard reasoning) is what most people converge on, so buy the local-capable machine only if you also value keeping email and family data off the network, which this plan does.

Section 3

Voice for the kids agent, and the machine topology

Two follow-up decisions came out of the hardware choice: whether the kids' Q&A should run a dedicated speech-to-speech model locally, and whether the 64 GB Mac mini should become a Studio, a cluster, or a pair of machines. The answers are linked. The voice design that is right for a child needs less memory than the alternative, which keeps the current plan on one machine, and it leaves a clean upgrade path that does not involve splitting a model across Macs.

Cascade, not end-to-end

The only credible open-weight speech-in, speech-out model in a size you can run is Qwen3‑Omni‑30B‑A3B‑Instruct: Apache 2.0, a Thinker that reasons and a Talker that streams audio, 19 speech input languages and 10 output languages including English.151 Its model card lists 79 GB at BF16 with the Talker for a 15-second clip; at 4-bit the weights drop to roughly 18–20 GB, with quantized paths through llama.cpp, LM Studio and Ollama but no official MLX support.151 Its successor Qwen3.5‑Omni (April 2026) "scales to hundreds of billions of parameters," beyond a Mac mini, and Qwen3.8‑Omni‑Flash (18 September 2026) is API-only with text output.152153 NVIDIA's PersonaPlex is a 7B Moshi-based full-duplex model with natural turn-taking, but it is CUDA-first with only a community MLX port and an NVIDIA Open Model License.154 Kyutai's Unmute, the reference cascaded stack, does not support macOS at all.155

The deciding factor is not memory but where the safety check sits. The plan's kid-safety control is a text classifier on both input and output. A cascade (speech-to-text, then the text model, then text-to-speech) exposes plain text at every stage, so the classifier can block an answer before it is ever spoken. An end-to-end model streams audio from the Thinker's internal state in parallel with its text, so there is no clean point to stop a bad answer before the child hears it. For an eight-year-old, that checkpoint is worth more than the second of latency the cascade adds.

The cascade is also what OpenClaw's Talk mode already does: it listens with the platform's native speech recognition, sends the transcript through the agent session, and speaks the reply through either macOS system voices or a local MLX text-to-speech provider, with cloud voices as an option you can leave unused.156157 The mlx-audio library covers the rest natively on Apple Silicon: Whisper, Parakeet, Qwen3‑ASR and Voxtral Realtime for speech-to-text; Kokoro, Qwen3‑TTS and Mistral's 4B open-weight streaming Voxtral TTS (March 2026) for speech-to-speech output.158159 The entire voice layer costs 3–8 GB, so Qwen3.8‑27B at Q8 stays exactly as planned. One speed caveat: a dense 27B at Q8 generates only about 7–8 tokens/second on the M5 Pro's 307 GB/s, so even with sentence-by-sentence streaming the first spoken sentence lands two to three seconds after the question. If that feels slow for a child, the kids agent can use the Qwen3.6‑35B‑A3B mixture-of-experts model instead (about 3B active parameters, roughly 50–60 tokens/second on this chip, ~20 GB at 4-bit, estimated from M4 Max measurements); the cascade and both classifiers stay exactly the same.98 Qwen3‑Omni remains a worthwhile experiment for an adult chat agent where sub-second turn-taking matters and no moderation gate is needed.

Cluster, or separate machines?

Two ideas travel under the word "cluster," and only one of them fits this plan. Splitting a single model across Macs is now officially supported: Apple added RDMA over Thunderbolt 5 in macOS 26.2, the feature covers the Mac Studio and the M5 Pro mini (the M6 mini has only Thunderbolt 4 and cannot join), and Apple claims up to 3× faster inference across four Studios.160163162 Jeff Geerling's four-Studio test ran a trillion-parameter Kimi K2 at about 30 tokens/second.161 But every generated token requires the nodes to exchange activations, so link latency is the ceiling; RDMA brings it under 50 µs against roughly 300 µs on Ethernet, which is why llama.cpp's Ethernet RPC mode slows down as nodes are added.161 For a 27B or a 30B‑A3B model that fits on one 48–64 GB mini, pooling adds cost and complexity and no speed; two 48 GB minis pooled give 96 GB at half the bandwidth of one Studio M5 Max 128 GB for similar money.

Separating roles is the good idea, and it mirrors the security tiers. The harness node holds everything sensitive: chat credentials, the Messages-signed-in account for iMessage, Gmail tokens, the browser profile, Langfuse. A model node holds nothing but weights and serves an OpenAI-compatible endpoint on the wired LAN or over Tailscale. A compromised skill on the harness gains no more than it would today, and a model server has no secrets to steal. OpenClaw already talks to Ollama or LM Studio over HTTP, so the split is a base-URL change rather than an architecture change,101 and each model gets its full bandwidth with no distributed inference in the loop. That is why the plan can start on one machine and grow into two or three without rework.

Network latency is a non-issue for the role split

An agent step is one HTTP request. On wired gigabit the round trip is well under a millisecond, while the model spends seconds processing the prompt and 30–60 ms per generated token; a 30k-token prompt is about 120 KB on the wire. Streaming tokens across the LAN adds nothing you can perceive, and 10 GbE is unnecessary. The rules are: wired, not Wi‑Fi, to avoid jitter; speech-to-text and text-to-speech stay on the harness box where the microphone and speaker are, so only text crosses the network, a few milliseconds against a one-to-two-second cascade budget. Latency only bites when a single model is split across nodes, because there it is paid per token rather than per request.

Decision

Current plan: one Mac mini M5 Pro (18-core CPU, 20-core GPU, 64 GB, 1 TB, 2.5 GbE; purchased at $3,199) runs the harness and all local models; the kids' voice loop is a cascade with the classifier on the text path; Qwen3‑Omni is loaded on demand for experiments only.

Upgrade trigger: when a local voice model earns daily use, or a 100B-class open model becomes worth running, add a model node rather than replacing the mini. By default the mini becomes the hardened harness box; if the new node is another mini, consider the reverse and keep this one, with its 20-core GPU, serving models. Choose the node by ambition: a second 48–64 GB mini for one model per node, or a Studio M5 Max 128 GB ($5,399 with 1 TB) if one node should hold both the voice model and a 120B MoE. Do not buy M6 minis expecting to cluster them, and do not pool models over Thunderbolt unless a model no longer fits on one machine.

Section 4

Security and privacy, by risk tier

Start from a fact the major labs and national security agencies now state plainly: prompt injection is not going to be solved. OpenAI says it "is unlikely to ever be fully 'solved'"; the UK NCSC says there is "a good chance" it is never eliminated, because a language model does not distinguish instructions from data; Microsoft calls it "an inherent risk."4948 The consequence for your design is that no filter is the thing you rely on. Safety has to come from limiting what a hijacked agent can do, and that limit has to live in code and permissions rather than in the prompt.

The threat model in one idea

Simon Willison's "lethal trifecta" is the most useful lens: an agent that has access to private data, is exposed to untrusted content, and has any channel to communicate externally can be made to steal the data.44 Every one of the proven attacks of the last eighteen months is an instance of it. EchoLeak (CVE-2025-32711, CVSS 9.3) was a zero-click email that made Microsoft 365 Copilot exfiltrate data through a rendered Markdown image.59 Brave showed a hidden Reddit comment steering Perplexity's Comet browser to read a user's email and one-time code and post them back.60 Invariant Labs showed one crafted WhatsApp message pulling a user's full chat history out through a WhatsApp MCP server.61 Anthropic's own red team on Claude for Chrome measured a 23.6% attack success rate without mitigations and 11.2% with them, which is still one in nine.51

Three further threats are specific to a self-hosted gateway. Supply chain: Koi Security found 341 malicious skills among 2,857 on ClawHub in February 2026, most installing the Atomic macOS Stealer to harvest Keychain, browser and wallet credentials; Snyk found 7% of skills leaking plaintext credentials; OpenClaw added VirusTotal scanning, which Unit 42 then showed being evaded by padded files carrying affiliate-fraud and pump-and-dump payloads.5358 The MCP ecosystem has its own history: the first malicious MCP server in the wild BCC'd every email to an attacker, and the MCP spec now documents confused-deputy, token-passthrough and tool-description injection risks as MUST-level concerns.62 Exposure: Bitsight saw more than 30,000 distinct OpenClaw gateways on the public internet in two weeks of early 2026, many with weak or no auth, and a Chinese user lost money to card fraud after binding the gateway to all interfaces with a VNC browser holding saved cards.55 Instruction loss: in February 2026 an OpenClaw agent deleted the inbox of Meta's alignment director after context compaction dropped her "don't act until I approve" instruction; she could not stop it from her phone.57 Prompt-level approval rules are not controls.

The decision rule: autonomous or ask?

And the gate is enforced in code, not the prompt. Fail any one and the task waits for a human who sees exactly what will happen.

The weekly ritual

A scheduled script pulls the week's metrics and scores from Langfuse and writes a short report: runs per use case, success and pass^k, cost, p95 latency, top failing graders, new or unusual skills and tools invoked, injection-canary results. You then spend thirty minutes reading ten to twenty transcripts (every failure plus a random sample of passes), add three to five new golden cases from real failures, and decide on one change (prompt, model or guardrail) that gets re-evaluated before it ships. Thumbs up and down from the chat surfaces land as Langfuse scores tied to the trace; thumbs-down and judge-fail traces go to an annotation queue you label yourself. Monthly, recompute the judge's true-positive and true-negative rates against those labels.

The stack in one line

OpenClaw diagnostics-otel → self-hosted Langfuse in Docker on the Mac (Phoenix if memory is tight) → promptfoo golden sets per use case, Inspect AI for sandboxed multi-step tasks → before_tool_call hooks that block sends and submits lacking an approval flag → weekly report and transcript review. License cost: zero. Running cost: judge-model API calls, kept on a small model and escalated only for nuanced rubrics.

Section 8

Roadmap

The order matters more than the pace. Each phase adds one tier of risk only after the previous tier is observable, so you always have traces and a test set before you give the agent something it could get wrong expensively.

  1. Phase 0
    Foundation: hardware, isolation, telemetry

    Mac mini M5 Pro, 18-core CPU / 20-core GPU, 64 GB, 1 TB, 2.5 GbE ($3,199, purchased), running the harness and all local models on one machine. Dedicated macOS user. OpenClaw pinned to a current release, gateway on loopback, Tailscale for remote access, Docker sandbox enabled, egress firewall, secrets in Keychain, budget caps on every API key. Langfuse running and receiving traces before any agent does real work.

  2. Phase 1
    Low tier: chat and Q&A

    Telegram first, iMessage second. Local Qwen3.6-35B-A3B for chat; Sonnet 5 escalation. Kid agent with no tools behind Llama Guard 4, voiced through the cascade (native speech recognition in, Kokoro or Voxtral TTS out via mlx-audio). First golden sets (20 cases each) and the weekly review ritual. Two weeks of traces before moving on.

  3. Phase 2
    Medium tier, read-only: email digest and trip research

    Gmail read-only via IMAP or a personal OAuth app; local model with fallbacks disabled; nightly digest to chat. Trip researcher with Maps Grounding Lite and web fetch, no payments. Injection canaries in both eval sets. Confirm the reader agent has no outbound tools by inspecting the trace, not the config.

  4. Phase 3
    Medium tier, act-with-approval: job hunting

    Discovery through Indeed MCP and alerts, drafting from a verified-facts file, a daily Approve / Edit / Skip digest, browser pre-fill with you on Submit. before_tool_call hook blocks any submit lacking an approval flag. Track ban and callback signals. Raise the daily cap only when hallucinated-qualification checks stay at zero across a month.

  5. Phase 4
    High tier, only if still wanted: scoped purchasing

    A separate payment agent that reads nothing untrusted, holds a single-use or merchant-locked virtual card with hard caps, and asks for a confirmation showing merchant, amount and card before every transaction. Revisit when network agentic tokens (Visa, Mastercard, AP2) reach consumers with issuer-side limits; until then, keep this phase small or skip it.
