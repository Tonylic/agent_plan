Where the research changed the roadmap's assumptions

  • Three pieces are separate plugins. In 2026.9.7, iMessage (@openclaw/imessage), Brave Search and the Prometheus exporter (@openclaw/diagnostics-prometheus) are installed from npm, not bundled. They're pinned at 2026.9.7 and must be updated together with OpenClaw.
  • Per-agent keys can't go through models auth paste-api-key. It stores the key itself in the agent's SQLite database. Per-person provider ids with Keychain SecretRefs keep every key in happy's Keychain instead; modelPolicy.allow stops one person's agent using another's provider.
  • main can't be renamed in place. Its database records its owner, and agents delete main refuses until openclaw doctor --fix moves the legacy shared auth store out of it (tested 2 Oct). D2–D3 add tony-main beside it, migrate, then delete.
  • A multi-agent config must say agents.ownership: "explicit", and the default 30-minute heartbeat would run a cloud turn and message the first allowlisted handle. Heartbeats are turned off.
  • web_search has to be allowed twice: in the agent's tools and in its sandbox tool list; otherwise it's filtered out without an error. TOOLS.md and HEARTBEAT.md are no longer injected; the hard rules live in AGENTS.md.
  • On iMessage, allowFrom is also the approver list, and native approval prompts need approvals.exec.enabled: true. A sandboxed command can never raise an approval, so E7 tests the path with the owner-only /diagnostics command, which always asks.
  • A dropped unknown sender is logged only at debug level, so E4–E6 run with debug logging and then switch it back.
  • The OpenAI-compatible endpoint can't be limited to loopback: with Tailscale Serve on, it's also reachable over the tailnet with the gateway token. The token already grants full operator access over the WebSocket API, so this adds a surface, not a credential.
  • promptfoo can't see OpenClaw's internal tool calls (OpenClaw continues a trace only for WebSocket requests that send traceparent), so happy-eval exports each eval session's trajectory and checks it itself. promptfoo still sends one "telemetry disabled" event per run even with telemetry off.
  • Grafana 13.2 treats its Prometheus datasource as a separate plugin kept current by a startup preinstaller (turned off here, so F2 installs it by hand and F5 checks it answers), and Grafana, macmon and node_exporter all listen on every interface by default; each is pinned to 127.0.0.1 here. For the metrics endpoint the docs show only the shared gateway token, which carries full operator access.
